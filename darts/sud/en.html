Flying Daggers Privacy Notice

This notice is provided by huang yu zhao, the developer of Flying Daggers. It explains how the game handles information when you play through SUD OpenPaaS and its host apps.

Game saves and preferences

The game stores your round progress, personal records (including high scores, fewest throws and daily challenge results), theme unlocks and selection, language, music, sound and vibration settings in the current host’s local storage. This lets the game restore your progress and preferences. If you haven’t selected a language, the game reads the language preference supplied by the host app to choose the interface language.

You can play without a separate game account. The developer’s game code does not upload your game saves or settings to a developer server or ask you for your nickname, profile picture, phone number or ID document. If vibration is enabled and supported, the game uses short vibrations for feedback. You can turn vibration off in settings.

SUD, host apps and web hosting

SUD and the host app run the mini game and deliver its assets. They may process device, network or diagnostic information under their respective privacy policies. See those policies for details about what they process and how to manage it.

This notice is a static page with no analytics scripts. When you access it through GitHub Pages, the hosting service may process access data separately. See the GitHub Privacy Statement for details.

Optional rewarded videos

If rewarded videos are available in your game version and host app, you can choose to watch one to unlock a theme or get extra knives. The game supplies the reward type to the ad interface and, when unlocking a theme, its identifier. It uses the viewing result returned by the interface to grant the reward. The game code does not pass your scores or local settings through this interface.

The host app or its advertising provider loads and displays the ads. See their privacy policies for details on the information they process and how to manage it. You can skip the feature and keep playing the main game.

Contact and data choices

If you contact the developer, we use your email address and message to respond and handle your request. We keep this information only as long as needed for that purpose, unless the law requires otherwise.

If the host app offers an option to clear mini-game data, you can use it to delete your saves and settings. The game cannot restore those records from a developer cloud save after you clear them.

To ask for access to, a copy of, correction of or deletion of personal information the developer handles, to withdraw consent, or to raise a privacy question or complaint, email huangyz192@gmail.com. For information handled by SUD, the host app or an ad provider, use the relevant service’s settings or contact channels.

Children and notice updates

Minors should play with guidance from a parent or guardian. If you are a guardian and believe a minor provided personal information to the developer without your consent, please contact us at the email address above so we can look into it.

If the game changes how it handles information, the developer will update this notice and notify you or ask for consent when required by applicable law.
