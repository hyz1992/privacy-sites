《小李飞刀》隐私保护指引

本指引由《小李飞刀》的开发者 huang yu zhao 制定，说明你通过 SUD OpenPaaS 及其宿主应用游玩时，游戏如何处理信息。

游戏存档与设置

游戏在当前宿主环境的本地存储中保存关卡进度、个人成绩（如最高分、最少用刀数和每日挑战纪录）、主题解锁与选择、语言及音乐、音效和震动设置，以便下次进入时恢复进度和偏好。对于尚未手动选择语言的玩家，游戏读取宿主应用提供的语言设置以选择界面语言。

游戏玩法无需注册独立游戏账号。开发者的游戏代码不会将这些游戏存档或设置上传到开发者服务器，也不会主动向你索取昵称、头像、手机号或身份证件。开启震动且当前环境支持时，游戏会触发短暂的震动反馈，你可以在游戏设置中关闭。

SUD、宿主应用与网页托管

SUD 和宿主应用提供小游戏运行和资源分发服务，可能按各自的隐私政策处理设备、网络或运行诊断信息。有关处理范围和管理方式，请查阅 SUD 及你所使用的宿主应用的隐私政策。

本指引为静态网页，页面本身没有统计脚本。通过 GitHub Pages 访问时，托管服务可能独立处理访问数据，详情见 GitHub 隐私声明。

可选的激励视频

当游戏版本和宿主提供激励视频时，你可以主动选择观看，以解锁主题或获得额外飞刀。游戏向广告接口传递奖励场景（解锁主题时还会传递主题标识），并根据接口返回的观看结果发放奖励。游戏代码不会通过该接口传递你的关卡成绩或本地设置。

广告的加载和展示由宿主或其广告服务商提供。有关广告服务处理的数据及管理方式，请查阅宿主及相关广告服务商的隐私政策。你可以跳过该功能并继续基本玩法。

联系开发者与管理数据

如果你联系开发者，我们会使用你的邮箱地址和来信内容回复并处理请求，并仅在处理请求所需期间保留这些信息，法律另有规定的除外。

如果宿主提供清除小游戏数据的选项，你可以用它删除游戏存档与设置。清除后，游戏无法通过开发者云存档恢复这些记录。

如需查阅、复制、更正或删除开发者处理的个人信息、撤回同意，或提出隐私问题或投诉，请发送邮件至 huangyz192@gmail.com。由 SUD、宿主或广告服务商处理的信息，请通过相应服务的设置或联系渠道管理。

未成年人保护与指引更新

未成年人应在父母或其他监护人的指导下游玩。监护人如认为未成年人未经同意向开发者提供了个人信息，可以通过上述邮箱联系我们核实处理。

如果游戏的信息处理方式发生变化，开发者会更新本指引，并在适用法律要求时通知你或征求同意。
