Ginger Cat: Memory Flip — Privacy Notice

This notice explains how huang yu zhao, the developer of Ginger Cat: Memory Flip, handles information when you play through SUD OpenPaaS in a host app.

Game saves and settings

The game uses local storage to keep your unfinished run, best score and highest round, tutorial progress, coins and items, music, sound and vibration settings, and counters for simulated ads. It uses this data to let you resume play, keep records and items, restore your settings, and limit how often simulated ads appear. The game updates this data as you play and keeps it locally until it is cleared.

You can play without creating a separate game account. The game code does not upload these saves to the developer’s servers or send data to ad providers. The current in-game ads are simulations. The game can trigger vibration if you turn it on and your environment supports it. You can turn vibration off in the game settings.

SUD, host apps and web hosting

SUD and the host app provide the runtime and deliver game assets. They may handle device, network and diagnostic data under their respective privacy policies. If the host uses the SUD-GI SDK, see the SUD-GI SDK privacy notice (Chinese) for details.

GitHub Pages hosts this notice. The page includes no analytics scripts. See the GitHub Privacy Statement for how the hosting service handles visit data.

Contacting the developer

If you email huangyz192@gmail.com, the developer uses your email address and message to respond and handle your request. The developer keeps this information only as long as needed to handle the request unless the law requires a different retention period.

Managing your saves and personal information

If the host app lets you clear mini-game data, you can use that option to delete your local saves and settings. The developer does not provide cloud saves, so the game cannot restore data you have cleared.

Email huangyz192@gmail.com to request access to or a copy of personal information handled by the developer, ask for corrections or deletion, withdraw consent, or raise a privacy question or complaint. For information handled by SUD or the host app, use the relevant platform’s settings or contact channels.

Minors and changes to this notice

Minors should play with guidance from a parent or legal guardian. If you are a parent or guardian and believe a minor provided personal information to the developer without your consent, please use the email address above so the developer can look into it.

If the way the game handles information changes, the developer will update this notice and notify you and seek consent when required by applicable law.
