《大橘翻翻乐》隐私保护指引

本指引由《大橘翻翻乐》的开发者 huang yu zhao 制定，说明你在 SUD OpenPaaS 及其宿主应用中游玩时，游戏如何处理信息。

游戏存档与设置

游戏在当前运行环境的本地存储中读写未完成的挑战、最高分和最高轮数、新手引导进度、金币与道具、音乐与音效及震动设置，以及模拟广告的次数记录。这些数据用于续玩、保留成绩和道具、恢复设置，以及限制模拟广告的出现次数。存档会随游玩进度更新，并保留在本地，直至被清除。

游戏无需注册独立账号。开发者的游戏代码不会将这些存档上传到开发者服务器，也不会向广告服务商发送数据。当前游戏里的广告为模拟流程。开启震动且运行环境支持时，游戏会触发震动反馈。你可以在游戏设置中关闭震动。

SUD、宿主应用与网页托管

SUD 和宿主应用提供小游戏运行及资源分发服务，可能按各自的隐私政策处理设备、网络和诊断信息。若宿主集成了 SUD-GI SDK，也可查阅 SUD-GI SDK 隐私协议。

本指引由 GitHub Pages 托管，页面本身不含统计脚本。托管服务如何处理访问数据，请参阅 GitHub 隐私声明。

联系开发者

如果你通过 huangyz192@gmail.com 联系开发者，开发者会使用你的邮箱地址和来信内容回复并处理请求。这些信息仅在处理请求所需的期限内保留，法律另有规定的除外。

管理存档与个人信息

如果宿主应用提供清除小游戏数据的功能，你可以使用它删除本地存档和设置。游戏没有开发者云存档，清除后无法通过游戏恢复。

如需查阅、复制、更正或删除开发者处理的个人信息，撤回同意，或提出隐私问题及投诉，请发邮件至 huangyz192@gmail.com。由 SUD 或宿主应用处理的信息，可通过相应平台的设置或联系渠道管理。

未成年人保护与指引更新

未成年人请在父母或其他监护人的指导下使用游戏。如果你是监护人，并认为未成年人未经你的同意向开发者提供了个人信息，请通过上方邮箱联系开发者核实处理。

如果游戏的信息处理方式发生变化，开发者会更新本指引，并在适用法律要求时通知你及征求同意。
