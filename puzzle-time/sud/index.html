《拼图时光》隐私保护指引

本指引由《拼图时光》的开发者 huang yu zhao 制定，说明游戏在 SUD OpenPaaS 及其宿主应用内运行时的信息处理方式。

游戏保存的信息

游戏在当前宿主的本地游戏存储中读取和保存故事解锁及完成进度、未完成棋盘、剩余时间、道具次数和设置偏好，用于继续拼图及恢复设置。游戏业务代码不把这些记录上传到开发者服务器，也不要求注册独立账号或提供昵称、头像、手机号或身份证件。

开启震动且宿主支持时，游戏调用宿主的短震动能力反馈拼图操作。你可以在游戏设置中关闭震动。

如果你主动联系开发者，开发者会使用你的邮箱地址和来信内容来回复并处理请求。联系信息仅在处理请求所需的期限内保留，法律另有规定的除外。

平台服务与资源分发

SUD 与宿主应用提供小游戏运行及资源分发服务，并可能根据各自的隐私政策处理设备、网络和诊断信息。集成相关 SDK 的宿主可参阅 SUD-GI SDK 隐私协议，了解兼容性和故障排查所涉及的信息。

本隐私页由 GitHub Pages 托管。页面本身不嵌入统计脚本，托管服务处理访问数据的方式见 GitHub 的隐私声明。

管理本地信息与行使权利

如果宿主提供清除小游戏数据的功能，你可以用它移除本地进度和偏好。本游戏没有开发者云存档，清除后的这些记录无法通过游戏恢复。

如需查阅、复制、更正或删除由开发者处理的个人信息，撤回同意，或提出隐私疑问和投诉，请联系 huangyz192@gmail.com。由 SUD 或宿主处理的信息，可通过相应平台的设置或联系渠道管理。

未成年人和指引更新

未成年人请在监护人指导下使用游戏。如果发现不满 14 周岁儿童的个人信息可能在未经监护人同意的情况下提供给开发者，请联系开发者核实和处理。

若游戏增加会改变个人信息处理方式的功能，开发者会更新本指引，并在适用法律要求时告知并征求同意。
